# Portfolio Website

Dies ist eine kleine Übungsseite aus meiner Umschulung zum Fachinformatiker Anwendungsentwicklung (2025–2027).  
Ziel ist es, einfache Projekte mit HTML, CSS und JavaScript auszuprobieren und den Umgang mit GitHub Pages zu lernen.

## Live-Demo und Quellcode
- Live-Demo: https://entilsa.github.io/portfolio/  
- Repository: https://github.com/EntilSa/portfolio

## Inhalte
- Preis-/Gewinnrechner: Berechnet Nettoerlöse nach Abzug von Gebühren, Versand, Einkauf und Mehrwertsteuer.  
- Währungsrechner: Umrechnung zwischen EUR, USD, GBP und CNY mit manuell eingestellten Kursen.  
- Magic Button: kleiner Hover-Effekt, Übung für DOM-Manipulation und Event-Handling.

## Ziel
Die Seite soll meinen aktuellen Lernstand zeigen. Ich bin im 6. Monat der Umschulung und setze hier einfache praxisnahe Beispiele um, auch mit Bezug zu meinen bisherigen Erfahrungen im E-Commerce.
